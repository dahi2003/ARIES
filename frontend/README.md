# Frontend - Smart Exam Copy Evaluation System

## Run locally

1. Install dependencies:
   - `cd frontend && npm install`
2. Start the app:
   - `cd frontend && npm run dev`
3. Open browser at `http://localhost:5173`

## Notes

- This frontend is built with Vite + React.
- The login page calls the backend `/api/auth/login` endpoint.
- Professor and student dashboards are scaffolded for role-based view.
